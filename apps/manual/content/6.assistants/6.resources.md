Besides tools, the server offers resources. All are JSON.

| URI | Name | Needs | Contents |
| --- | --- | --- | --- |
| `arx://tabs` | Granted tabs | `read` | The granted tabs |
| `arx://tabs/{tabID}` | Granted tab | `read` | One tab's inventory item |
| `arx://tabs/{tabID}/snapshot` | Page snapshot | `pageContent` | A fresh semantic snapshot of the tab |
| `arx://downloads` | Downloads | `downloads` | Downloads of whole-profile grants |
| `arx://events` | Browser events | `read` | What happened in granted tabs, while the client subscribes |

## Subscriptions

Subscribe to a tab to follow its navigation and loading, or to `arx://downloads` to follow downloads. Arx sends `notifications/resources/updated` for the URI when it changes, and `notifications/resources/list_changed` when the set of granted tabs changes. A connection can hold up to 256 subscriptions.

## Browser events

Subscribe to `arx://events` to hear about granted tabs without polling. Arx records events while the subscription lasts and sends `notifications/resources/updated` for `arx://events` when there are new ones. Read `arx://events?after=N` for the events after sequence number `N`; `next` is the newest.

| Event | When |
| --- | --- |
| `tabOpened`, `tabClosed` | A granted tab appears or goes away, including by a grant change. |
| `navigated` | The tab went to another address. |
| `loadStarted`, `loadFinished` | The page started or finished loading. |
| `pageError` | The page failed to load; `errorCode` is Chromium's network error. |
| `dialogOpened` | The page opened a JavaScript dialog; `dialog` says which kind. |
| `permissionPrompt` | The page asked for a permission. |
| `downloadsChanged` | Something in the granted downloads changed (with `downloads`). |
| `tabChanged` | The tab changed in a way the others don't name, such as a reload. Arx looks every few seconds, so a load that starts and finishes in between shows up this way. |

Each event has a `sequence`, the `tabID` and the tab's new `revision`, never the address, title or dialog text: read the tab's resource for those. Arx keeps the newest 200, and clears them when the client's grant changes.

## Tool list changes

When the person changes a client's grant, the server sends `notifications/tools/list_changed` and the tool list shows only what the new grant covers. The client stays connected.
