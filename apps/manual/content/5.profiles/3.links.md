## Copy a link

| Command | What you get |
| --- | --- |
| Copy Current URL (:keys{combo="⇧ ⌘ C"}) | The address as it is |
| Copy Clean Link | The address without tracking parameters such as `utm_*`, `gclid`, `fbclid` and `msclkid`, and the share tags of sites such as YouTube and Amazon |
| Copy Original Link as Markdown | `[Title](address)` |
| Copy Proxy Link | The address after your first matching Proxy Link rule |
| Copy Proxy Link as Markdown | The same, as Markdown |
| Share Proxy Link | The proxy link, through the macOS share menu |
| Copy Saved Link | A pinned tab's saved address, not where it is now |

They're in the Tabs menu, the address bar, a tab's or Favorite's menu, and a link's context menu on the page. Right-click one of several marked tabs and the command covers all of them.

The proxy commands (Copy Proxy Link, Copy Proxy Link as Markdown and Share Proxy Link) only appear where they can do something: on a site one of your enabled [Proxy Link rules](#proxy-links) matches. On any other site:

- The address bar's menu, a tab's or Favorite's menu and a link's menu leave them out. With several marked tabs, they're there when at least one tab's site matches.
- The Tabs menu and the command bar show them dimmed, so you can still find them, and their shortcuts do nothing.

Clean Copy removes only parameters it knows:

- About sixty tracking parameters on every site, such as `gclid`, `fbclid`, `msclkid`, `mc_eid` and `_hsenc`, and any parameter starting with `utm_`, `pk_`, `piwik_`, `mtm_`, `matomo_`, `hsa_` or `itm_`.
- On some sites, their own share and referral tags: `si` on YouTube and Spotify, `s` and `t` on X, `trk` on LinkedIn, `igsh` on Instagram, `share_id` on Reddit, and on Amazon `ref`, `pd_rd_*`, `pf_rd_*` and the `/ref=…` at the end of the path. The same names on other sites are left alone.

Everything else stays as it was: other parameters and their order, encoded paths and the part after `#`. Links with signature or authentication parameters stay exactly as they are, so they keep working. **What Clean Copy removes** in **Settings → Links** lists every rule.

To share the page's own address with its title, use **File → Share…**, the command bar, or the page's right-click menu.

## A link's menu

Right-click a link on a page for:

- **Open Link in New Tab**, **Open Link in New Window** (on the same space) and **Open Link in Private Window**, then **Open in Peek** and **Open in Little Arx**. In [Little Arx](/tabs/little-arx#where-links-open) there's no Open Link in New Tab, and **Open in Main Window** comes last.
- **Download Linked File**, into the profile's downloads folder.
- The copy commands above, **Share…** with the link as it is, and **Share Proxy Link** when a Proxy Link rule matches the link's site.
- **Inspect Element** in [developer mode](/developers/developer-mode).

A link in a private window offers the copy and share commands only.

Every link has this menu, as in Chrome: one on another port, such as `http://localhost:3000`, one with a username and password in it, an email link or a phone link. What's in it depends on the link:

- Web links (`http` and `https`) offer everything above, with a few exceptions:
  - A link to a site no enabled Proxy Link rule matches has no proxy commands.
  - A link on another port, such as `http://localhost:3000`, has no Copy Clean Link or proxy commands.
  - A link with a username and password has no Download Linked File or Copy Clean Link. Proxy links and Share Proxy Link leave the username and password out; Copy Original Link keeps them.
- Other links, such as `mailto:` and `tel:`, offer **Copy Link** and **Share…**. For an email link it reads **Copy Email Address** and copies just the address, without `mailto:` or a subject. Arx doesn't open these links itself, so the Open items, Download Linked File and the clean and proxy commands aren't there.

## After you copy

A small toast at the top right of the window says what's on the clipboard: **Copied Current URL**, **Copied Clean Link**, **Copied Proxy Link**, **Copied Markdown Link**, or how many links you copied. It goes away by itself after a couple of seconds and stays while the pointer is over it. It never takes the keyboard from the page.

In [Split View](/tabs/split-view), the toast shows at the top right of the pane whose link you copied, so you can tell which tab it means. That's the focused pane, or the pane of the tab or link you right-clicked. Sharing works the same way.

- The share button opens the macOS share menu for the copied link.
- **Copy Original** appears when cleaning or a Proxy Link rule changed the link, and copies the address as it was.
- With Proxy Links, **⋯** copies or shares the link through another matching rule.

If the clipboard couldn't be written, the toast says so instead.

## Proxy Links

Some sites preview badly when you paste their links into a chat. A Proxy Link rule swaps the host when you copy or share, for example `x.com` to `fxtwitter.com`.

Set them up in **Settings → Links → Proxy Links**, a page that lists your rules; its row in Links shows how many there are. Each one has a switch to turn it off without deleting it. The first enabled rule that matches wins, so order matters: drag a rule by the handle on its right, or press :keys{combo="⌥ ⌘ ↑"} or :keys{combo="⌥ ⌘ ↓"} while the rule has keyboard focus. **Move Up** and **Move Down** are also in the rule's right-click menu and in VoiceOver's actions.

Arx starts with three rules. The path, query and fragment always come along:

| Rule | Links from | Become |
| -- | -- | -- |
| Instagram (kkinstagram) | `instagram.com`, `www.instagram.com` | `kkinstagram.com`, so `www.instagram.com/reel/…` becomes `kkinstagram.com/reel/…` |
| X (fxtwitter) | `x.com`, `twitter.com`, and their `www.` and `mobile.` hosts | `fxtwitter.com`, so `x.com/user/status/…` becomes `fxtwitter.com/user/status/…` |
| TikTok (vxtiktok) | `tiktok.com` and any subdomain of it | `vxtiktok.com`, keeping the subdomain: `vm.tiktok.com/…` becomes `vm.vxtiktok.com/…` |

If you already had a rule for one of these sites when Arx added them, Arx left that site's default out, so your rule still decides. You can delete these three like any rule of yours. A default you delete stays deleted, after you quit and reopen Arx and after an update. **Restore Default Links** brings all three back as Arx ships them, after your own rules, so yours still come first.

Click **New Rule** to add one. A rule has a name, one or more source hosts and a template that can use `{host}`, `{path}`, `{query}` and `{fragment}`. A template that starts the host with `{subdomain}`, as in `https://{subdomain}vxtiktok.com{path}`, also matches the source hosts' subdomains and carries the subdomain over. **Test a link** in the same sheet shows what the rule, as you've typed it so far, and Copy Clean Link make of a link. **Save** (:keys{combo="↩"}) stays dimmed until the rule is valid; **Cancel** (:keys{combo="Esc"}) closes the sheet without changing anything.

Click a rule to edit it in the same sheet, or **Delete** it there. Right-clicking a rule offers both too, and when you reach a rule with the keyboard, :keys{combo="Delete"} deletes it.

How the link previews then depends on the third-party service you point it at.
