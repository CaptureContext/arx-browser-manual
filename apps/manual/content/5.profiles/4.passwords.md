When you sign in to a site, Arx offers to save the password. Saved passwords belong to one profile: a work profile never sees your personal passwords, and the other way round.

::preview{scene="save-password"}
::

## Saving

After you sign in, Arx shows **Save password for** the site, with the username you used:

- **Save** keeps it in this profile.
- **Never** stops Arx from offering for this site in this profile.
- **Not now** skips it this time.

When you sign in with a new password for a site you've saved, Arx offers **Update password** instead. **Keep old** keeps the saved one.

## Filling

Click a username or password field on a site you've saved a password for, and Arx lists the saved accounts right below the field. Pick one and Arx fills the username and the password. The list shows only usernames and sites, never a password.

::preview{scene="password-fill"}
::

- Click an account, or use the **↓** and **↑** keys, then **Return**. **Esc** closes the list.
- Before it fills, macOS asks for Touch ID or your Mac password, as it does when you show a password in Settings. To fill without asking, turn off **Settings → General → Autofill → Ask before filling passwords**.
- **Manage…** at the bottom of the list opens this profile's passwords in Settings.
- It works the same in [Split View](/tabs/split-view) panes, [Little Arx](/tabs/little-arx) and [Peek](/tabs/peek).

Arx never fills a password into a page on its own when the page opens. An assistant can ask Arx to [sign in with one](/assistants/sign-ins#signing-in-with-a-saved-password); Arx asks you first unless you've let agents sign in to that site without asking, and the assistant never sees the password.

Passwords are stored by the browser engine in the profile's own folder, encrypted with Arx's key in your macOS Keychain, the same key that protects your cookies. If Arx can't read that key, it asks you instead of making a new one: see [The key to your passwords and cookies](/help/privacy#the-key-to-your-passwords-and-cookies).

## Managing saved passwords

Open **Settings → Profiles**, pick a profile, and click **Passwords** under its data. The list shows only that profile's passwords, by site and username. It never shows the passwords themselves.

::preview{scene="passwords"}
::

- The magnifier in the sheet's bar opens a search that filters by site or username. **Add Password…** and **Import…** sit beside it.
- **Copy Password** puts the password on the clipboard. macOS asks for Touch ID or your Mac password first. Arx marks it as concealed, so clipboard managers that respect that don't keep it, and clears it after a minute if you haven't copied anything else.
- **Show Password** (in the row's **…** menu) asks the same way, then shows the password until you close it.
- **Edit…** changes the username or the password. Leave the password empty to keep the saved one.
- **Remove** deletes the password from this profile. Arx asks first.
- **Add Password…** saves a password for a site you type in, such as `example.com`. If that site already has a password for the same username, Arx says so and changes nothing.

**Never saved** lists the sites where you chose **Never**. Remove one and Arx offers to save passwords there again.

**Sign-in without asking** lists the sites in this profile where you let assistants [sign in with a saved password](/assistants/sign-ins#signing-in-with-a-saved-password) without asking you. Remove a site to be asked again.

## Importing from Chrome or Apple Passwords

Click **Import…** and pick a CSV file:

- **Chrome:** in Chrome's Password Manager, open **Settings → Export passwords**.
- **Apple Passwords:** in the Passwords app, choose **File → Export All Passwords**.

The browser engine reads the file itself, and the passwords go straight into this profile, never into any other. Two-factor codes (the `OTPAuth` column in Apple's export) aren't imported. When the import ends, Arx tells you how many passwords it imported, which ones it kept because that site and username were already saved, and which rows it skipped, such as a row without a password. Arx doesn't delete the file, so delete it yourself once you're done; it holds your passwords in plain text.

## Private windows

[Private windows](/tabs/private-windows) never save passwords and never offer them for filling. Settings only lists your profiles, so a private window has no password list.
