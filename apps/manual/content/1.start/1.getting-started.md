Arx is a browser for the Mac. It has spaces for each part of your day, one bar for everything, and a sidebar that remembers. The interface is native and written in Swift; underneath it runs a Chromium engine derived from Helium, so sites work as they do in Chrome. Chrome extensions run per profile; see [Extensions](/profiles/extensions) for what's supported today.

Arx is free and open source under the GPL-3.0 licence. There is no account to create and no paid plan.

::note
Arx is in public beta. It's ready for every day and still has rough edges: tell us what you run into with [Send Feedback](/help/send-feedback). See [what's new](/help/release-notes) in each version.
::

## What you need

A Mac with Apple silicon and macOS 27 or later. Arx doesn't run on Intel Macs.

## Install Arx

[Download Arx](https://arxbrowser.net/download) from arxbrowser.net, or get `Arx.dmg` from the [latest release on GitHub](https://github.com/capturecontext/arx-browser/releases/latest). Both are the same disk image.

1. Open the disk image.
2. Open Arx from it. You don't need to drag it anywhere.

Arx moves itself to your Applications folder, opens again from there and ejects the disk image. If an older Arx is already installed, it goes to the Trash first, so you can still get it back. If that older Arx is running, Arx brings it to the front instead and replaces nothing; quit it and open the disk image again to update.

If Applications needs an administrator password, macOS asks for it. If you cancel, Arx goes to the Applications folder in your home folder instead.

If you open Arx from somewhere else, such as Downloads, it asks whether to move to Applications. Choose **Not Now** to keep it where it is for now, and tick **Don't ask again** to stop the question. After a move, the copy in Downloads goes to the Trash.

If the move fails, Arx keeps running from where it is and says why. Choose **Move to Applications…** in the Arx menu to try again.

## First launch

Arx opens with a short welcome, and the browser window appears when you finish it or close it. Until then, New Tab, the command bar and New Window are unavailable, and links you open in Arx from other apps wait and open as soon as the browser window appears. If this Mac is signed in to iCloud, the welcome first offers to [sync with iCloud](/profiles/sync#during-setup): on a second Mac, that brings the profiles and spaces your other Mac syncs instead of starting over. From there you can import your tabs from another browser, or start fresh with one profile and one space. If Claude Code or the Codex CLI is signed in on this Mac, you can also [connect it as the assistant](/command-bar/chat#connect-during-setup). You can reopen the welcome any time with **Welcome to Arx…** in the Arx menu or the command bar.

The welcome starts with a short tour: Peek, Split View, the command bar, chats and Little Arx, each a looping demo on sample data. In the chats demo, the **Chats** command opens the chat beside a page, **Summarize the page** is chosen and a short summary streams in. **Continue** moves through the tour, the pause button beside "A demo on sample data." holds a demo still, and **Skip Tour** moves past it.

Arx starts you in a profile and a space both named **Default**, with no tabs. If you chose **Sync with iCloud** and iCloud already had your Arx, Default is removed and you start in what iCloud brought. Otherwise what happens to it depends on the import:

- If you import into new profiles, for example one per Arc profile, Arx removes Default when the welcome ends, so only your imported profiles remain and the browser window opens in an imported space. It does this only while Default is still empty: no tabs, Favorites, history, saved passwords, extensions or changed settings.
- If you import into Default itself, skip the import or start fresh, Default stays as your profile. Rename it in Settings › Profiles if you like.

Your profiles and spaces are stored on this Mac, and in iCloud too once you turn on sync. When you quit, Arx closes every window and reopens them the next time you launch it. They open on the empty page, with every folder collapsed, unless you turn off [Open to an empty page at launch](/start/settings#quitting-and-starting).

## Four keys to start with

::shortcut-table
---
rows:
  - [Open the command bar, ⌘ K]
  - [New tab, ⌘ T]
  - [Edit the address, ⌘ L]
  - [Show or hide the sidebar, ⌘ S]
---
::

Everything else is in [Keyboard shortcuts](/start/keyboard-shortcuts), and every binding can be changed in Settings.

## Where windows reopen

With **Settings → Advanced → Restore previous windows at launch** on, ordinary windows reopen at their saved position and size, including their full-screen state. If a display has been disconnected, Arx moves its windows onto a display that is still connected. New windows cascade from the front browser window. Private windows aren't restored.
