Arx updates itself. **Settings → General → Updates** shows when it last checked, with **Check Now** beside it, and the same check is **Arx → Check for Updates…** in the menu bar.

Updates come from the [releases of Arx's GitHub repository](https://github.com/capturecontext/arx-browser/releases), signed by the Arx team, and Arx checks that signature before it installs one. Builds you make yourself from the source never update.

## Checking and installing

| Setting | Default | What it does |
| --- | --- | --- |
| Check for updates automatically | Arx asks the second time you open it | Checks once a day in the background. |
| Download and install automatically | Off | Downloads an update when Arx finds one, and installs it the next time you quit Arx. Needs automatic checks. |
| Update channel | The channel you downloaded | **Stable** or **Beta**. See below. |

An update always installs when Arx quits. **Install and Relaunch** quits Arx the usual way, so a page that asks before closing or **Warn before quitting** can still keep it open, and downloads in progress stop, to resume from Downloads next time. If something keeps Arx open, the update waits: Settings shows **Quit and Install**, and it installs at the next quit either way. Arx doesn't reopen by itself after installing.

Arx only installs a newer version than the one you have. Your profiles and data move forward with each version, so going back to an older one isn't offered.

## Stable and Beta

**Settings → General → Updates → Update channel** picks which versions you get:

- **Stable** gets versions once they're ready for everyone.
- **Beta** gets new versions first, and every stable version too, so you're never behind Stable.

Switching from Beta back to Stable never installs an older version. You keep the version you have until a newer stable version comes out, and get that one as usual.

A copy of Arx downloaded as a beta starts on Beta; one downloaded as a stable release starts on Stable. Your choice in Settings replaces it. While Arx is in public beta, every release is a beta, so new copies start on Beta.

## What's New

The first time you open Arx after an update, a short **What's New** sheet lists what changed in that version. **Full Release Notes** opens the [full release notes](/help/release-notes) in a new tab; **Continue** or :keys{combo="Esc"} closes the sheet. It shows once per version. If you installed the new version from a downloaded disk image, the sheet only names the version and links to the release notes.
