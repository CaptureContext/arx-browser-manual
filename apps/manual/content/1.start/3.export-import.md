Arx can write your setup to a file and read it back, on this Mac or another one. You need no account, and nothing goes through a server.

## Export

In **Settings → Advanced**:

- **Export Archive…** saves an Arx archive: your profiles, spaces, folders, pinned tabs, Favorites and preferences.
- **Export Bookmarks…** saves a bookmarks HTML file that other browsers can import.

Two switches decide what else goes into an archive: **Include browsing history in archives** and **Include the Tab Archive in archives**. Both start off each time. The export shows its progress, and you can cancel it.

## What an archive holds

| Included | Not included |
| --- | --- |
| Profiles: name, search engine, appearance, Favorites | Cookies and signed-in sessions |
| Spaces: name, icon, appearance, pinned and open tabs, folders | Passwords and passkeys |
| Preferences: appearance, search shortcuts, keyboard shortcuts | Air Traffic Control rules |
| History and the Tab Archive, if you switch them on | Assistant grants |
| Your extensions, listed by name to reinstall | The extensions themselves |

An archive is one JSON file, format `dev.capturecontext.arx.transfer`, version 2, up to 64 MB. Arx also reads version 1 archives.

## Import

Import an archive or a bookmarks file through the [migration assistant](/start/bring-in): **Settings → Advanced → Import…**, then choose the file. You get the same review, categories and destinations as for another browser, and importing the same archive twice doesn't duplicate anything.
