Press :keys{combo="⇧ ⌘ N"} for a **New Incognito Window**. Each private window has its own cookies and site data, which go away when you close it.

## Its profile

A private window belongs to the profile you opened it from: the profile of the window in front, or, from another private window, the one that window belongs to. As in Chrome's incognito windows:

- Only the profile's [extensions](/profiles/extensions#private-windows) you allow in private windows run there. They have an **Allow in private windows** switch, off until you turn it on. Their buttons are in the window's [site menu](/pages/site-menu#private-windows).
- It follows some of the profile's [site settings](/profiles/site-settings): what you set for cookies, JavaScript, pop-ups, images, sound and content blocking carries over, and so do zoom levels. A site you blocked from the camera, microphone, location or notifications stays blocked; one you allowed asks again.
- Nothing it does changes the profile: it keeps no history, and its cookies and site data stay in the window.

While a private window is open, its profile can't be removed.

## What's different

- Nothing in it is saved: not its tabs, not its pinned tabs, not its history.
- The command bar only knows the pages of this window.
- Profiles, Little Arx, Media, the Tab Archive and Route URL aren't available in it. [Content blocking](/pages/content-blocking) is: ads and trackers are blocked there too.
- Links don't open in Peek there.
- Assistants connected through [MCP](/assistants/connect) never see private windows, and there's no [chat](/command-bar/chat) in them.

Downloads from a private window appear under **Private Transfers** in [Downloads](/pages/downloads) and keep going after the window closes. They go to the [downloads folder](/pages/downloads#where-files-go) of the profile whose window you opened the private window from, and ask where to save when that profile does.

## Save Page As and Print

**File → Save Page As…** works in a private window too. It saves the page as a complete web page, its HTML only, a web archive (`.mhtml`) or a PDF, and a PDF document the window shows as itself. The save appears under Private Transfers. Arx keeps nothing else: the save panel remembers the folder you chose only until you quit Arx, and ordinary windows' save panels don't learn it.

**File → Print…** prints a private page, or the PDF document it shows, as in a regular window. Arx reads the page for the print panel in memory and keeps no copy.
