Open **Window → Downloads**, the Downloads section of the Library, or search for it in the command bar.

For a quick look at your latest files, rest the pointer on the Library button at the bottom of the sidebar: your recent downloads fan out above it, and a click opens one. See [the sidebar](/tabs/sidebar#width-hiding-and-the-library).

## The Downloads panel

- The current profile's downloads, until you filter them.
- Search by name.
- **Filter**, beside the search field, opens **Filter Downloads**. Pick one or more profiles to see only their downloads, or **Private Transfers** for downloads from private windows. **Done** closes it.
- Filters that are on show as chips under the search field, and Filter shows how many. Click a chip to remove it; with none left, you're back to the current profile.
- The Downloads window (**Window → Downloads**) picks **Current Profile**, **All Profiles** or **Private Transfers** from a menu instead.
- **Cancel** a download in progress, **Open** a finished one, or **Show in Finder**.
- With [Sound feedback](/start/settings#sound-feedback) on, a finished download plays a short sound, even while Arx is in the background, and a failed one a low one. Cancelling makes no sound.
- **Pause** a download in progress and **Resume** it later. A download that stopped because you quit Arx, or because the connection dropped, shows **Resume** too: it carries on from what it already has when the site allows that, and starts over when it doesn't.

## A download's menu

Control-click a download, in the Library or the Downloads window:

- **Open** and **Show in Finder**, for a finished file.
- **Pause** or **Resume**, and **Cancel**, while it downloads.
- **Copy Link** copies the address the file came from.
- **Remove from List** takes a finished, cancelled or failed download off the list. The file stays where it is.
- **Move to Trash** moves a finished file to the Trash and takes it off the list.

Private downloads leave the list when their private window's session ends, so they have no Remove from List or Move to Trash.

Files go to the profile's downloads folder, your Downloads folder unless you change it. If a file with the same name is already there, Arx adds a number. Files flagged as dangerous are blocked, and you can cancel them.

Right-click a link for **Download Linked File**, which saves to the profile's downloads folder (not in private windows). It asks for the file as the link's page, as Chrome does, so a site that only hands a file to its own pages still sends it. Right-click an image, a video or audio for **Save Image As…**, **Save Video As…** or **Save Audio As…**, which ask where to save; see [Right-click menus](/start/keyboard-shortcuts#right-click-menus).

A [connected assistant](/assistants/tools) with the downloads class can start a download too. Arx asks you first, and the download shows up here like any other.

Quitting Arx stops downloads in progress, paused ones too, and they show **Resume** here the next time you open Arx; Arx doesn't ask first. With **Warn before quitting** on, the **Quit Arx?** dialog says how many will stop. A download in a private window, or one whose site can't resume it, would be lost by quitting, so Arx asks about it even with that warning off.

## A link that downloads a file

When a link or an address turns out to be a file, Arx downloads it. That's no page error:

- **A tab that was showing a page keeps it.** The download shows in this list as usual.
- **A tab with nothing to show**, such as a new tab the link opened, an address you typed in a new tab, a Little Arx or Peek, shows a calm **Downloading** page instead: the file's name and icon, the site it came from, and its progress, then **Downloaded**.
  - **Open** and **Show in Finder** once it's finished.
  - **Cancel** while it downloads, and **Resume** if it was paused or can carry on.
  - A cancelled or failed download says so plainly, with **Retry**, which asks the site for the file again.

## Where files go

Each profile has its own downloads folder. In **Settings → Profiles**, pick a profile and find **Downloads**:

- **Change…** picks another folder. **Use Downloads** goes back to your Downloads folder.
- **Ask where to save each file** shows a save panel before each download starts, including downloads an assistant starts.

A private window uses the settings of the profile whose window you opened it from. If your organization sets the folder, it shows here and can't be changed.
