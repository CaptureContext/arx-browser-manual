# Issue tracker

Use GitHub issues and pull requests in [capturecontext/arx-browser-manual](https://github.com/capturecontext/arx-browser-manual) for work on the manual. Keep plans, decisions and work status in the issue or the pull request that carries the change.

What Arx itself does and plans comes from [capturecontext/arx-browser](https://github.com/capturecontext/arx-browser): its code, its issues and the website changelog. Link an app issue from a manual issue when a page waits on it.
